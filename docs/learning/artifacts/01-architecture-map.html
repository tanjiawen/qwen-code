📦 核心包
🧠
@qwen-code/qwen-code-core
packages/core/
Agent 引擎 — 与 UI 无关的纯逻辑。LLM 调用、工具系统、权限、MCP、Memory、子Agent。
  • src/core/ — Agent 主循环 (client.ts, geminiChat.ts, turn.ts)
  • src/tools/ — 工具定义与注册
  • src/permissions/ — 权限模型
  • src/providers/ — LLM 提供商适配
  • src/memory/ — 持久化记忆
  • src/mcp/ — MCP 协议集成
  • src/subagents/ — 子 Agent 调度
  • src/hooks/ — 生命周期钩子
  • src/config/ — Config 配置中心
  • src/services/ — 后台服务 (压缩、循环检测等)
🖥️
@qwen-code/qwen-code (CLI)
packages/cli/
终端交互层 — React 19 + Ink 7 渲染 TUI，yargs 解析命令，会话管理，非交互模式。
  • src/cli.ts — CLI 入口路由 (serve/mcp/help/default)
  • src/gemini.tsx — main() 启动序列 (1330行)
  • src/ui/ — Ink 组件 (AppContainer, 主题, 对话框)
  • src/config/ — settings.ts, auth.ts, hot-reload.ts
  • src/commands/ — 子命令 (mcp, extensions, sessions)
  • src/nonInteractive/ — 非交互模式执行器
  • src/serve/ — HTTP daemon 模式
  • src/i18n/ — 国际化
