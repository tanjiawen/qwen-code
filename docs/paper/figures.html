Figure 5

Five-Layer Defense-in-Depth Security Architecture

L1 · Prompt Layer — System Prompt Hardening

Safety instructions Role boundaries Output constraints

Threats: social engineering, role hijacking, instruction injection

L2 · Tool Declaration Layer — Schema & Capability Bounds

FunctionDeclaration schema Kind classification Deferred loading (tool_search)

Threats: parameter injection, capability escalation

L3 · Tool Intrinsic Permission — Default Policy

getDefaultPermission() requiresUserInteraction() permissionAliases

Threats: unauthorized file writes, dangerous shell commands

L4 · PermissionManager Rules — User-Defined Overrides

evaluatePermissionRules() Allow-list / Deny-list Path-conditional rules

Threats: scope creep, repeated approval fatigue

L5 · Approval Mode & Hooks — Runtime Enforcement

ApprovalMode (DEFAULT/AUTO_EDIT/YOLO/PLAN) PreToolUse / PostToolUse hooks Auto-mode classifier

Threats: runtime bypass, hook evasion, denial-state fallback
